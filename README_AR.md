# مترجم المانجا / المانهوا إلى العربية

نسخة معدّلة من [Manga-AutoTranslate](https://github.com/amirwolf5122/Manga-AutoTranslate) تُخرج **ترجمة عربية** بدل الفارسية، وتعمل **محلياً بالكامل** عبر Ollama.

## ما الذي تغيّر
| الملف | التعديل |
|---|---|
| `arabic_prompts.py` (جديد) | برومبت عربي كامل (فصحى مبسّطة)، إضافة للهجة المصرية، ونسخة خفيفة للنماذج المحلية الصغيرة |
| `manga.py` | اختيار لغة الهدف (`--target-lang ar/fa`) واللهجة (`--ar-dialect msa/egyptian`)، وفحص الخط بالحروف العربية، ودعم Ollama (مهلة أطول، JSON mode، موديل افتراضي `qwen2.5:7b-instruct`) |
| `manga_app.py` | العربية هي الافتراضية، واسم الملف الناتج ينتهي بـ `_ar` |
| `run_local_ar.sh` / `.bat` (جديد) | تشغيل محلي: يتأكد من Ollama ويحمّل الموديل ويشغّل المشروع |
| `Manga_Translator_Colab_AR.ipynb` (جديد) | نسخة كولاب ترفع هذا المشروع بدل سحب الأصلي |

اللغة الفارسية ما زالت متاحة: `--target-lang fa`.

## التشغيل المحلي (بدون إنترنت بعد أول تشغيل)
1. ثبّت Python 3.10+ و [Ollama](https://ollama.com/download).
2. من مجلد المشروع:
   - لينكس/ماك: `./run_local_ar.sh`
   - ويندوز: `run_local_ar.bat`
   
   أو مباشرة: `./run_local_ar.sh "مجلد_الصور" out.pdf`
3. أول مرة فقط يحتاج إنترنت لتحميل: موديل Ollama (~4.7GB لـ 7B) ونماذج الكشف/OCR/المسح (RT-DETR وLaMa) ومكتبات Python. بعدها كل شيء يعمل محلياً.

متغيّرات مفيدة: `OLLAMA_MODEL` (مثلاً `qwen2.5:14b` لجودة أعلى إن توفرت ذاكرة)، `MANGA_AR_DIALECT=egyptian`، `USE_GPU=1`.

## الكولاب
افتح `Manga_Translator_Colab_AR.ipynb`، شغّل الخلية الأولى وارفع `Manga-AutoTranslate-AR.zip`، ثم الخلية الثانية. استخدم مفتاح Gemini في الواجهة (مجاني) لسرعة أعلى.

## أوامر CLI مباشرة
```
python manga.py -i input -o out.pdf --font fonts/Vazirmatn-Bold.ttf \
    --provider ollama --model qwen2.5:7b-instruct --target-lang ar --ar-dialect egyptian --cpu
```

## ملاحظات صريحة
- الترجمة المحلية بنموذج 7B أضعف من Gemini/GPT؛ قد تحتاج مراجعة، وأفضل نتيجة محلية مع نموذج 14B فأكثر.
- على CPU ستكون سرعة الترجمة والمسح (LaMa) بطيئة؛ GPU يحسّن كثيراً.
- واجهة البرنامج ورسائل السجل تُرجمت إلى العربية (آلياً، فقد تجد صياغة تحتاج تحسيناً). البرومبت الفارسي القديم بقي كاحتياطي لـ `--target-lang fa`.
- لو عندك ملف إعدادات قديم من النسخة الفارسية (config)، احذفه لتجنب قيم قديمة مثل خيار الإخراج «پوشهٔ تصاویر».
- لم أجرّب الواجهة الرسومية/الويب فعلياً بعد الترجمة (تحققت بالـ compile ومقارنة بنية الكود وأن النصوص التي يعتمد عليها الـ JS متطابقة).
- لم أجرّب التشغيل الكامل على صفحات حقيقية (لا يوجد GPU/Ollama في بيئتي)؛ اختبرت البرومبت واختيار اللغة والرسم العربي بالخط ومسار الـ CLI.
